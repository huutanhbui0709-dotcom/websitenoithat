# Nội Thất Vinhomes Văn Nghĩa - Website Hoàn Thiện Căn Hộ

Website giới thiệu dịch vụ thiết kế & thi công nội thất căn hộ Vinhomes cao cấp (Grand Park, Ocean Park, Smart City, Golden River, Central Park...).

## Tính Năng & Thiết Kế
- **Thiết kế Responsive 100%**: Tối ưu hiển thị hoàn hảo trên Mobile (360px - 430px), Tablet (768px - 1024px) và Desktop (1280px - 1920px).
- **Thanh Header Cao Cấp (Atelier Luxury Minimal)**: Khóa cứng `whitespace-nowrap` chống ngắt dòng, logo monogram vector sắc nét.
- **Menu Mobile Off-Canvas Drawer**: Ngăn kéo trượt mượt mà với hiệu ứng làm mờ nền (backdrop blur).
- **Bộ Lọc Dự Án**: Tab lọc theo phân khu (VGP, SMC, OCP, Luxury) với thao tác vuốt chạm cảm ứng mượt mà.
- **Công Cụ Dự Toán Chi Phí 60s**: Tính toán chi phí ước tính theo diện tích m² và gói thi công theo thời gian thực.
- **Accordion FAQ & Form Khảo Sát**: Trải nghiệm tương tác mượt mà và tối ưu kích thước nút bấm chuẩn di động.
- **Thanh Thao Tác Nhanh (Floating Action Bar)**: Thanh điều hướng dán đáy trên điện thoại và nút Back-to-top trên máy tính.

## Khởi Chạy Nhanh
Mở trực tiếp tệp `index.html` trên bất kỳ trình duyệt nào hoặc chạy live server:
```bash
python -m http.server 8089
```
Truy cập: `http://localhost:8089/`
